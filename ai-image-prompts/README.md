## What is this?

This is a collection of 50 ready-made prompts for generating images with the current generation of AI image tools: **Midjourney V7**, **ChatGPT** (GPT Image), **Gemini** (Nano Banana), **Adobe Firefly**, **Ideogram** and **Flux**.

If you have ever typed something like *"a woman at a cafe"* and got a flat, generic result — this is why. AI image tools need detail: lighting, camera angle, mood, style, and context. The prompts below are already written with all of that built in.

## How to use this

1. Find a prompt in the category that matches what you want to create
2. Copy the full prompt from inside the code block
3. Paste it into your AI image tool (ChatGPT, Gemini, Midjourney, Firefly, etc.)
4. Replace any part in `[brackets]` with your own details
5. For even better results, enhance the prompt first at [PromptIt](https://promptitin.com/image-prompt-generator?utm_source=github&utm_medium=prompt-library&utm_campaign=image&utm_content=how-to)

> **Tip for beginners:** In ChatGPT or Gemini, just paste the prompt into the chat and it creates the image. No extra steps needed.
>
> **The `--ar` and `--v` at the end are Midjourney settings.** In ChatGPT, Gemini or Firefly, delete them and say the shape in words instead, e.g. *"vertical 4:5 image"*.
>
> **2027 tip:** Modern image models follow plain sentences better than keyword lists. If a result is off, add one sentence describing what's wrong ("the hands look unnatural, fix them") instead of starting over. ChatGPT and Gemini can also edit an image you upload: paste the prompt and attach your photo.
